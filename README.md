Job Application Tracker

A sleek, mobile-friendly web app built with Flask and SQLite to help users track job applications efficiently. It allows users to add, edit, delete, and filter applications with a polished, modern UI.
Features
	•	Add / Edit / Delete job applications
	•	Status filtering: Applied, Interview, Offer, Rejected
	•	Live search: Find applications by company, title, or notes
	•	Status summary badges: Visual overview of how many jobs are in each stage
	•	Responsive design: Optimized for desktop and mobile
	•	Color-coded cards with hover animations and icons
	•	Built with: Flask, SQLite, HTML/CSS, JavaScript
Tech Stack
	•	Backend: Flask (Python)
	•	Database: SQLite
	•	Frontend: HTML, CSS (with Inter font), JavaScript
	•	Hosting: Replit (development), GitHub (repository)
 How to Run Locally
	1.	Clone the repository: git clone https://github.com/dreadgod11/job-tracker.git
cd job-tracker
Set up a virtual environment:python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
Install dependencies:pip install flask
Run the app: python app.py
Visit: http://localhost:5000
